# 同学共享许可协议（Classmate Sharing License Agreement）

给同学提供 Python 作业答案的时候，一位同学的不当转载行为引发了争议，~~<del style="text-decoration: line-through !important;">这是我不希望看到的</del>~~[^lei_meme]，所以[托 DeepSeek R1](https://chat.deepseek.com/share/9zw9f3ju8eaivuxt03) 写了个适合私下传作业答案的开源协议。

[^lei_meme]: 来自[磊哥游戏](https://space.bilibili.com/268941858/)《[王者荣耀就是个巨大的杀猪盘，时机成熟人人皆是牢玩家](https://www.bilibili.com/video/BV1u3WLzeEn6/)》 1 分 55 秒：“我们发现有些坦克故意出肉装，然后故意去扛伤，这是我们不希望看到的。”

## 协议简要说明

1. 你可以随便使用、修改代码（或别的作业），并且随便转发给同学。
2. 你不得把源代码或者与之相关的事情透露给老师或学校，不管是故意的还是不小心的。
3. 你转发的时候必须注明原作者，并且同样遵守这个协议。
4. 因为使用或传播代码（或别的作业）产生的任何问题与纠纷，原作者概不负责。

## 文件版本说明

* `LICENSE-python.txt` 是专门写给 Python 代码的协议，主要针对用微信转发 Python 代码片段的情形。
* `LICENSE` 把“Python 代码”换成了任何形式的作业，包括但不限于文档、PPT、图表、手写内容等。

把对应的协议文件或者链接与声明夹带到你的源代码或其它形式的作业中，就算用上这个文件了。
